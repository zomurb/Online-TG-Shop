Это полностью переработанная и улучшенная версия Telegram-магазина. Теперь код разделен на модули для удобства поддержки и расширения, а также добавлены новые функции для пользователей и администраторов.

---

## 🚀 Новые возможности

### 👤 Для пользователей
- 🔍 **Поиск по товарам**: Мгновенный поиск товаров по описанию или категории.
- ❤️ **Избранное**: Сохраняйте понравившиеся товары, чтобы не потерять их.
- 👤 **Личный кабинет**: Просматривайте свои данные, историю заказов и общую сумму покупок.
- 🔙 **Улучшенная навигация**: Кнопки "Назад" во всех подменю.
- 👟 **Выбор размера**: Интегрированная система выбора характеристик товара.

### 👑 Для администраторов
- 📊 **Панель статистики**: Просмотр общей выручки, количества пользователей, заказов и среднего чека.
- 📝 **Редактирование товаров**: Изменяйте цену, количество или описание существующих товаров без их удаления.
- 🎟 **Улучшенные промокоды**: Более гибкая настройка скидок и сроков действия.
- 📦 **Управление заказами**: Удобный фильтр заказов по статусам (new, processing, delivered, cancelled).

## 🏗 Структура проекта
```text
Online-TG-Shop/
├── src/
│   ├── database/       # Работа с БД (SQLite)
│   ├── handlers/       # Логика бота (User & Admin)
│   ├── keyboards/      # Сборка меню и кнопок
│   ├── states/         # FSM состояния
│   ├── main.py         # Точка входа
│   └── config.py       # Конфигурация
├── requirements.txt    # Зависимости
└── README_V2.md        # Эта документация
```

## ⚙️ Технологии
- **Python 3.x**
- **Aiogram 3.x** (современный асинхронный фреймворк)
- **SQLite**
- **Pydantic** (для валидации данных в Aiogram)

---

## 🛠 Установка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте токен бота в `src/config.py` или через переменную окружения `BOT_TOKEN`.
3. Запустите бота:
   ```bash
   python src/main.py
   ```
